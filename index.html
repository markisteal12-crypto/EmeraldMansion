PSP Save Editor

PPSSPP & PSP save data — runs entirely in your browser

Drop a save folder here

Each PSP save is a folder like ULUS10041DATA00 containing PARAM.SFO, ICON0.PNG and the game's data file (often DATA.BIN). You can drop the whole SAVEDATA folder too — or drop a cheat.db to browse codes.

Where PPSSPP keeps saves
Windows: Documents\PPSSPP\PSP\SAVEDATA (or memstick\PSP\SAVEDATA next to PPSSPP.exe)
macOS / Linux: ~/.config/ppsspp/PSP/SAVEDATA
Android: PSP/SAVEDATA in your PPSSPP storage folder
Nothing is uploaded — files never leave this page. Back up your save before editing.
